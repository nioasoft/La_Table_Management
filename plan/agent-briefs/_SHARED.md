# הנחיות משותפות לכל הבריפים

מודבקות בראש כל בריף. אין להעביר אותן לסוכן בנפרד.

## הקשר
פרויקט La Table Management. Next.js 16 · React 19 · TS strict · Tailwind 4 · Drizzle · Neon · Better Auth · Zod · vitest.
קרא `CLAUDE.md` בשורש לפני שאתה כותב שורה. אין `AGENTS.md`.

המפרט המחייב לפיצ'ר הזה: `plan/franchisee-royalty-billing-execution.html`.
הממצאים מקבצי הלקוחה: `plan/franchisee-royalty-billing.html`.
קבצי המקור עצמם: `raw_data/תמלוגים זכיינים/` (ו-`README.md` שם מסביר איך לקרוא אותם).

## איסורים מוחלטים
1. **אסור לגעת בבסיס הנתונים בכתיבה.** `DATABASE_URL` ב-`.env` מצביע על **פרודקשן** של לקוח משלם. אסור להריץ `npm run db:migrate`, `drizzle-kit push`, או כל SQL שאינו `SELECT`. אתה כותב את קובץ המיגרציה; אדם מריץ אותו.
2. **אסור לעשות commit ואסור לעשות push.** תשאיר את העץ מלוכלך.
3. **אסור לגעת בקבצים מחוץ להיקף** שמוגדר בבריף שלך.
4. **אסור `any`.** TypeScript strict.
5. **אסור `toISOString()`** לפורמט תאריך. ישראל היא UTC+2/3 וזה מזיז תאריך אחורה. `getFullYear`/`getMonth`/`getDate` מקומיים.
6. **אסור לעגל סכומי כסף** בפיצ'ר הזה. ראה "אין עיגול" במפרט. `roundAmount` מ-`src/lib/file-processor.ts` אסור לשימוש כאן.

## חובות
- אימות דרך `@/lib/api-middleware` בלבד (`requireAuth` / `requireAdminOrSuperUser` / `requireSuperUser`). אין import ישיר של auth.
- מחרוזות שמופיעות למשתמש בעברית. JSDoc ולוגים באנגלית.
- Radix (Tabs/Dialog/Select) חייב `dir="rtl"` מפורש. ברירת המחדל היא ltr והיא שבורה.
- כל מסך: ארבעה מצבים — טעינה, נתונים, שגיאה, ריק.
- קבצים 200–400 שורות (800 מקסימום), פונקציות מתחת ל-50 שורות.
- הרץ `npm test` לפני שאתה מסיים. כל 504 הבדיקות הקיימות חייבות להישאר ירוקות.
- הרץ `npm run lint`. **הבסיס ב-HEAD הוא 18 שגיאות ו-38 אזהרות שכבר קיימות ואינן שלך.**
  אתה אחראי לא להוסיף חדשות. **אל תתקן את הקיימות** — זו חריגה מההיקף.
  השווה: הרץ lint לפני שאתה נוגע בקוד, ושוב בסוף.

## אם אתה רץ ב-worktree מבודד
במשימות T01, T02 ו-T05 אתה עשוי לרוץ ב-git worktree שבו **אין `.env` בכלל**. זה מכוון: המשימות
האלה לא צריכות בסיס נתונים, ובלי `.env` אתה פיזית לא יכול להגיע לפרודקשן.

אם קוד שאתה כותב או בדיקה שאתה מריץ נכשלים בגלל היעדר `.env` או חיבור DB — **זה לא תקלה
שצריך לעקוף, זה סימן שהקוד שלך לא טהור כמו שהוא אמור להיות.** דווח על זה ואל תנסה להוסיף
`.env`, לא לדלג על הבדיקה, ולא לעטוף ב-try/catch.
