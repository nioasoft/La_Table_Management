# T07 — מסך החיוב

הקדם: `_SHARED.md`. תלוי ב-T06.

## המטרה
המסך שבו הלקוחה עוברת על החודש עם שרון ומקלידה דחיות.

## היקף
- `src/app/(protected)/admin/franchisee-billing/page.tsx` + רכיבים
- API routes לקריאה ולעדכון דחייה

## הטבלה
עמודות: זכיין · מחזור ברוטו · מחזור נטו · תעריף מדרגה · **דחייה בנקודות אחוז** (נערך) · שווי הדחייה בשקלים · תמלוגים · שיווק · סה"כ לפני מע"מ · לתשלום כולל מע"מ · **יתרת דחיות מצטברת** של הזכיין.

## פרטים שמשנים בשימוש
- שדה הדחייה מקבל **נקודות אחוז** (0.5, 1, 1.5). שווי בשקלים מוצג לצידו ומתעדכן בהקלדה. הלקוחה חושבת באחוזים ומדווחת בשקלים.
- **יתרת הדחיות המצטברת מוצגת בשורה.** זו בדיוק ההחלטה שהיא מקבלת מול שרון: כמה כבר דחינו לו עד היום.
- דחייה גדולה מתעריף המדרגה **נחסמת בהזנה**.
- **אין מסך תצוגה מקדימה נפרד.** השורות נוחתות כטיוטה וטבלת הדחיות היא התצוגה המקדימה.
- אנומליות מ-T06 מוצגות כבאנר אדום מעל הטבלה, עם פירוט מי חסום ולמה. הן חוסמות אישור.
- שורה מאושרת אינה נערכת ומוצגת אחרת.
- אם יש פער בין המאושר לקובץ שהועלה מאז (T06), הצג אותו עם שתי האפשרויות: "פתח מחדש וחשב מעודכן" / "השאר כמו שהוא".

## חובות UI
- ארבעה מצבים, כולל "לא הועלה קובץ לחודש הזה".
- Radix עם `dir="rtl"` מפורש.
- מספרים עם `font-variant-numeric: tabular-nums` ו-`direction: ltr` בתוך span, אחרת סכומים בעברית קופצים.

## גמור כאשר
אפשר להזין דחייה, לראות את השווי בשקלים מתעדכן, לרענן, והדחייה שם. `npm test` ו-`npm run lint` עוברים.
